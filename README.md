## 🇰🇷 한국어 패치 설치 방법 (Windows)

### 1. Upscayl 설치

공식 GitHub에서 Upscayl 2.15.0을 다운로드하여 설치합니다.

https://github.com/upscayl/upscayl/releases/tag/v2.15.0

### 2. 프로그램 종료

Upscayl이 실행 중이라면 완전히 종료합니다.

### 3. 원본 파일 백업

Upscayl 설치 경로의 `resources` 폴더로 이동합니다.

일반적인 설치 경로 예시는 다음과 같습니다.

`C:\Program Files\Upscayl\resources\`

설치 환경에 따라 경로가 다를 수 있으므로 실제 `app.asar` 파일 위치를 확인해 주세요.

기존 `app.asar`를 `app.asar.backup`으로 백업합니다.

### 4. 한국어 패치 적용

1. `upscayl 2.15.0 KoreanPatch.rar`의 압축을 해제합니다.
2. 추출한 `app.asar.korean`의 파일명을 `app.asar`로 변경합니다.
3. 이름을 변경한 파일을 Upscayl 설치 경로의 `resources` 폴더에 복사합니다.
4. 기존 `app.asar` 파일을 교체합니다.
5. Upscayl을 다시 실행합니다.

### 5. 원상복구

한국어 패치 적용 전 상태로 돌아가려면 Upscayl을 종료하고, 패치된 `app.asar`를 제거한 후 백업한 `app.asar.backup`을 `app.asar`로 복원합니다.

**주의 사항**

- Upscayl 2.15.0을 대상으로 제작한 패치입니다.
- 다른 버전과의 호환성은 검증되지 않았습니다.
- 프로그램 업데이트 또는 재설치 시 패치가 초기화될 수 있습니다.
- 파일 교체에 관리자 권한이 필요할 수 있습니다.
- 적용 전에 반드시 원본 파일을 백업해야 합니다.

## 🇺🇸 English — Upscayl 2.15.0 Korean Language Patch

### Overview

Upscayl Korean Patch is an unofficial Korean localization patch for Upscayl v2.15.0 on Windows.

The Korean translation was created by **Sakai (WEZARD4U'S BLOG / 꿈을꾸는 파랑새)**.

Sakai forked the official Upscayl GitHub repository, translated the application into Korean, and submitted the translation as a contribution to the upstream project.

Submission to the upstream project does not imply that this independently distributed patch is an official Upscayl release.

### Installation

1. Download and install the official Upscayl v2.15.0 for Windows.
2. Close Upscayl completely.
3. Locate the `resources` folder in the installation directory.
4. Back up the original `app.asar` file.
5. Extract `upscayl 2.15.0 KoreanPatch.rar`.
6. Rename `app.asar.korean` to `app.asar`.
7. Replace the existing file in the `resources` folder.
8. Restart Upscayl.

To restore the original application, close Upscayl and restore the backed-up `app.asar` file.

Compatibility with other Upscayl versions has not been verified.
